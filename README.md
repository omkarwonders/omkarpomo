# omkarpomo

A highly functional, aesthetic Pomodoro app with data analysis capabilities.

## Features (Planned)
- ⏱️ Customizable Pomodoro, Short Break, and Long Break timers
- 📊 Data Analysis (Daily overview, productivity heatmaps)
- ☑️ Task Management integration

## Tech Stack
- Next.js
- Tailwind CSS
- Framer Motion
- Recharts
